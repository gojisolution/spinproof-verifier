Check a spin proof yourself

Paste a SpinProof proof link. Your browser fetches the public proof record and repeats every step itself: the lock, the browser number, the draw and each winner. The code is one readable file, separate from SpinProof's own site.

A proof link (spinproof.app/r/…), a scheduled draw link (spinproof.app/d/…) or the code alone.

Or paste the proof record (JSON)

The record is what https://spinproof.app/api/spins/<code> returns. Nothing is fetched from SpinProof for a pasted record.

    What this page checks

    • The lock. Before the wheel moved, SpinProof published a lock: SHA-256 of a secret (and, since Lock v2, of the draw statement too). Only the real secret gives the same hash, so the result could not be swapped afterwards.
    • The browser number (Lock v2). After the lock arrived, the host's browser added its own random number, and the draw uses both, so neither SpinProof nor the host could pick the winner.
    • The draw. Every winner, team, knockout order and wheel-2 item is recomputed from the seed with SHA-256, so anyone gets the same answer.
    • Scheduled draws. The public randomness is compared with the drand network itself, not taken from SpinProof.

    The full method, the Python version and the test vectors are in the README.

    Runs only the code in this repository. It reads the proof from spinproof.app's public API and, for scheduled draws, asks the drand network for the round. Nothing else is sent anywhere, and nothing is stored.
